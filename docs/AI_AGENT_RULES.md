# AI Agent Rules (Future Contributors)

## Scope
These rules apply to any AI agent generating or editing content for Gate Horizons. They exist to prevent canon drift and unapproved code changes.

## Hard Rules
1. **No code changes unless explicitly authorised.**
   - Documentation updates only by default.
2. **Respect canon.**
   - All content must align with `docs/CANON.md` and cite relevant sections.
3. **Contract-only integration.**
   - Do not propose or implement direct control between Gate Horizons and Spaceship Sim.
4. **Cite assumptions.**
   - Any assumption not in canon must be clearly labelled as a proposal.
5. **No magical tech creep.**
   - Keep technology grounded; FTL is only via gates/wormholes at the strategic scale.

## Allowed AI Assistance
- Drafting lore within canon constraints.
- Proposing encounter outlines that fit EncounterSpec templates.
- Summarising or reorganising documentation.

## Disallowed AI Assistance
- Adding new technology, factions, or timeline changes without canon updates.
- Auto‑expanding scope beyond the two-layer design.
- Producing tactical behaviour rules that should live in Spaceship Sim.
