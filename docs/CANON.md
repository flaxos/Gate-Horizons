# Canon Constraints (Single Source of Truth)

## Purpose
This document is the authoritative, versioned record of hard constraints for Gate Horizons. All lore, factions, timelines, and technological assumptions must align with this file. If something is not in canon, it is not guaranteed and must be proposed explicitly.

## Canon Pillars
- **Gate/wormhole FTL** exists only at the strategic timescale (weeks/months between systems).
- **Local spaceflight** is sub‑FTL and handled by Spaceship Sim (RCS + Epstein drive).
- **The Convergence** built the gate network and shut it down ~100,000 years ago.
- **Humanity discovers a dormant gate** in the Solar System, catalysing expansion.
- **Factions, economy, and research** are strategic-layer concerns in Gate Horizons.

## Versioning
- Canon changes require:
  1. A clear proposal with rationale.
  2. Update to this file with a new semantic version entry.
  3. A migration note describing how existing content remains valid.
- **Minor changes**: clarifications or corrections.
- **Major changes**: new technology, timeline shifts, or lore that alters gameplay assumptions.

## Canon Version History
- **v1.0.0** — Initial canon lock for Gate Horizons meta layer and tactical integration.

## Guardrails
- Canon stability is more important than novelty.
- LLM‑assisted content must cite the canon sections it relies on.
- Any new idea that changes the scope of a canon pillar is rejected unless formally versioned here.
