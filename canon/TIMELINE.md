# Prequel Timeline — “The Dust Moon Protocol” (Working Title)

Assumed era: late 21st / early 22nd century.

## ERA 0 — The Quiet Find (Year 0–1)
- Y0 M0: Survey flags HERMES-K, a dusty mini-moonlet with an unstable light curve.
- Y0 M3: Radar/occultation suggests internal reflectors; object is not homogeneous.
- Y0 M7: Robotic flyby detects micro-magnetic/gravity anomalies inconsistent with rubble.
- Y1: International scientific consortium forms; public attention spikes.

## ERA 1 — The First Touch (Year 2–4)
- Y2: Landing probe drills and deploys seismics; wave propagation is too coherent.
- Y2–3: Low-frequency tomography maps a ringlike void inside.
- Y3: First direct imaging indicates a torus/arch of unknown alloy.
- Y4: Classified as non-human origin. Politics intensify.

## ERA 2 — The Global Project (Year 5–9)
- Y5: Permanent belt station funded; industrial-scale tug + drone operations begin.
- Y6: Dust moon stabilised via controlled ablation/anchoring to reduce shedding.
- Y7: First power injection triggers millisecond field event (no aperture).
- Y8: Data suggests the gate contains a “pre-solved” field geometry.
- Y9: Three blocs emerge: Open Science, Defence Control, Corporate Exploitation.

## ERA 3 — First Activation (Year 10)
- Y10 M2: Sustained field stability achieved for ~21 seconds.
- Y10 M2: An aperture appears as a sharp “absence” in sensor expectations.
- Y10 M2: Micro-probe SPARROW-1 is fired through on a ballistic path.
- Y10 M2: Gate collapses. Telemetry later returns, proving a destination.

## ERA 4 — The First System (Year 10–12)
- Y10–11: Sol gate shows one stable outbound link.
- Y11: Repeat activations; probes map destination: dim red star + debris + abandoned orbital lattice.
- Y12: Evidence of prior civilisation: structured materials, artificial isotopes, non-natural orbital distributions.

## ERA 5 — Crewed Crossing (Year 13–15)
- Y13: First gate-rated crewed ship built: rugged, radiation-hardened, fail-safe heavy.
- Y14: First crewed crossing succeeds; Sol observes live exit telemetry.
- Y15: Multiple dead/damaged/sealed gates detected in destination system.

## ERA 6 — The “Dead Network” Realisation (Year 16+)
- Sol is a stub, not a hub. The broader network is fragmented — and appears deliberately constrained.
