# AI Agent Rules (Canon + Visual Consistency)

## Scope
Agents may generate or edit documentation, lore, prompts, and storyboard materials. No runtime code changes unless explicitly authorised.

## Non-negotiables
- CANON.md is the law. If there’s a conflict, update the draft, not canon.
- Hard sci-fi texture always. No “rule of cool” physics cheats.
- Gate artefacts are structural, not decorative. No glyph spam.
- Human tech remains utilitarian, safety-driven, and slightly ugly.

## Content generation rules
- Always declare assumptions when canon is silent.
- Prefer adding canon constraints before adding new lore.
- Keep Sol a dead-end spur (stub gate) unless canon explicitly changes.
- When writing gate activation visuals: “absence/wrongness”, not swirling portal.

## Drift control
- Use STYLE_BIBLE.md for every image prompt.
- Use STORYBOARD.md scene IDs; do not invent extra scenes without updating storyboard.
- Maintain strategic vs tactical timescale separation:
  - months-scale traversal at meta layer
  - real-time ship operations at tactical layer (Spaceship Sim)
